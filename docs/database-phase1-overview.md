# 数据库管理一期：实施总览

## 目标
一期目标是完成数据库管理模块的最小可用闭环：实例纳管、凭据绑定、连接测试、元数据同步、结构浏览、只读查询和查询审计。所有写操作默认不开放。

## 一期边界
### 包含
1. 新增 `资产管理 -> 数据库管理` 菜单和页面入口。
2. 数据库实例 CRUD。
3. 绑定现有凭据模块。
4. 支持 MySQL / MariaDB / PostgreSQL / Redis / MongoDB 类型建档。
5. MySQL / MariaDB / PostgreSQL 连接测试。
6. MySQL / MariaDB / PostgreSQL 基础元数据同步。
7. Redis / MongoDB 一期先完成实例建档和连接测试占位，深度发现后续补齐。
8. Schema、表、字段、索引结构浏览。
9. 只读 SQL 查询控制台。
10. 查询审计日志。
11. 基础权限点和管理员保护。

### 不包含
1. INSERT / UPDATE / DELETE / DDL 等写操作。
2. 生产恢复。
3. 审批流。
4. 数据库账号授权管理。
5. 自动修复和 SQL 自动优化。
6. 按库表粒度授权。
7. 完整备份恢复能力。

## 菜单与路由
1. 菜单名称：`数据库管理`
2. 菜单路径：`/asset/databases`
3. 前端路由：`asset/databases`
4. 前端组件：`web/src/views/asset/DatabaseManagement.vue`
5. 后端接口前缀：`/api/v1/databases`

## 一期交付拆分
1. 第 1 批：基础骨架、表结构、实例 CRUD、前端列表。
2. 第 2 批：连接测试、凭据绑定、支持类型列表。
3. 第 3 批：元数据同步、结构浏览。
4. 第 4 批：只读 SQL 控制台和 SQL 安全拦截。
5. 第 5 批：查询审计、权限收口、验收补齐。

## 当前进度
1. 第 1 批已完成：菜单、路由、AutoMigrate、实例 CRUD、前端实例管理页。
2. 第 2 批已完成：支持类型列表、凭据绑定、MySQL / MariaDB 连接测试。
3. 第 3 批已完成 MySQL / MariaDB 主链路：同步 Schema、表、字段、索引，记录同步任务，并在前端结构浏览中展示库、表、字段和索引。
4. 第 4 批已完成 MySQL / MariaDB 主链路：只读 SQL 控制台、SQL 类型识别、安全拦截、单语句限制、查询超时、最大返回行数限制和查询审计写入。
5. 第 5 批已完成查询审计列表和导出主链路：按实例、状态、风险、SQL 类型和关键字筛选，支持分页、SQL 详情查看和 CSV 导出。
6. 已完成数据库管理按钮级 RBAC 权限点，包含实例、连接测试、元数据、查询和审计导出权限。
7. PostgreSQL 已完成一期适配：连接测试、元数据同步和只读查询。
8. Redis、MongoDB 当前仍为一期占位能力，后续按适配器补齐连接测试、元数据同步和查询。

## 优先数据库类型
1. MySQL / MariaDB：一期主力，优先实现连接测试、元数据同步和只读查询。
2. PostgreSQL：一期主力，优先实现连接测试、元数据同步和只读查询。
3. Redis：一期先实现类型建档和连接测试，命令控制台后续分批。
4. MongoDB：一期先实现类型建档和连接测试，集合浏览后续分批。

## 安全默认值
1. SQL 控制台默认只允许只读语句。
2. 默认禁止多语句。
3. 默认查询超时 30 秒。
4. 默认最大返回 500 行。
5. 默认最大导出 5000 行。
6. 所有查询必须审计。
7. 数据库管理接口按按钮级 RBAC 权限校验，admin 角色自动放行。

## 验收标准
1. 管理员能打开 `资产管理 -> 数据库管理` 页面。
2. 能新增、编辑、删除、启用、禁用数据库实例。
3. 能绑定现有凭据。
4. MySQL / PostgreSQL 连接测试能返回版本和延迟。
5. 能同步并查看库、表、字段、索引。
6. 能执行只读 SELECT 并分页展示结果。
7. 非只读 SQL 会被拒绝。
8. 每次 SQL 执行都有审计记录。
9. 有权限的用户能按筛选条件导出查询审计 CSV。
10. 非授权用户访问数据库管理接口会被 403 拦截。
