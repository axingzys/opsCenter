# 虚拟化平台管理二期：验收与回归测试清单

## 1. 验收范围
1. 虚拟化平台接入与同步
2. 虚机纳管预检查与冲突策略
3. 主机详情联动
4. 状态回流与趋势展示

## 2. 环境准备
1. 已部署最新 `opshub-api:latest` 与 `opshub-web:latest`
2. 数据库已包含虚拟化平台相关表与 `virtualization_platform_metrics`
3. 已准备至少 1 套 ESXi 或 PVE 测试环境
4. 资产管理中已存在若干主机数据，用于纳管匹配与联动验证

## 3. 功能验收清单
### 3.1 平台管理
1. 新增 ESXi/PVE 平台成功
2. PVE 账号输入 `root` 时，页面提示带 realm，例如 `root@pam`
3. 点击“连通性测试”可返回成功或明确失败原因
4. 点击“同步”后可生成同步任务，并更新最近同步时间与状态

### 3.2 拓扑视图
1. 页面可展示平台数、集群数、宿主机数、虚机数汇总
2. 平台卡片下可展示集群与宿主机层级
3. 宿主机卡片可展示名称、管理 IP、状态、虚机数量
4. 切换平台筛选后，拓扑与趋势图同步刷新

### 3.3 虚机纳管
1. 虚机列表可展示名称、外部 ID、IP、系统、电源状态、纳管状态
2. 已绑定虚机可显示对应资产主机名称
3. 点击已绑定主机名称，可打开资产主机详情
4. 纳管弹窗可展示预检查面板、风险等级、检查项、建议主机
5. 选择建议主机后可完成纳管
6. 已存在历史绑定记录时，再次纳管不会触发唯一键冲突

### 3.4 冲突策略
1. 策略为 `strict` 时，高风险冲突会阻断纳管
2. 策略为 `warn` 时，高风险冲突仅提示，不阻断纳管
3. 设置修改后重新打开纳管弹窗，预检查行为与策略一致

### 3.5 状态回流与趋势
1. 已纳管虚机可展示“联动状态”
2. 资产主机在线时，联动状态显示“在线”
3. 资产主机离线时，联动状态显示“离线”
4. 平台同步后会写入趋势快照
5. 拓扑页可查看 `24h / 7d / 15d` 趋势图

## 4. 回归测试清单
### 4.1 同步相关
1. 平台同步不影响原有平台列表分页与筛选
2. 同步失败时，平台状态与任务失败原因能正确展示
3. 重复同步不会造成虚机、宿主机、集群重复插入

### 4.2 纳管相关
1. 已绑定虚机重复纳管时，系统提示当前绑定关系，不新增重复绑定
2. 解绑后再次绑定同一虚机，可成功复用历史记录
3. 无 IP 虚机仍可打开纳管弹窗，并得到明确风险提示

### 4.3 主机联动
1. 从虚机页跳转到主机详情后，主机基础信息正常展示
2. 不存在或已删除的主机绑定关系，不会导致虚机列表报错

### 4.4 前端展示
1. 平台页在桌面端与常见笔记本分辨率下布局正常
2. 表格、弹窗、趋势图无乱码
3. 错误提示文案可读，不暴露内部堆栈

## 5. 建议测试数据
1. 1 个 PVE 平台，至少 1 个集群、2 台宿主机、10 台以上虚机
2. 其中至少 1 台虚机已纳管到资产主机
3. 至少 1 台虚机只有标签 IP，没有 guest agent IP
4. 至少 1 台虚机无 IP，用于验证中风险预检查

## 6. 通过标准
1. 功能验收清单全部通过
2. 回归测试清单无阻断性问题
3. 平台同步、虚机纳管、主机联动三条主流程可连续完成
