# 数据库管理一期：前端实施细化

## 页面入口
1. 路由：`/asset/databases`
2. 组件：`web/src/views/asset/DatabaseManagement.vue`
3. API：`web/src/api/database.ts`
4. 页面标题：`数据库管理`
5. 页面副标题：`统一纳管数据库实例，支持结构发现、只读查询和审计`

## 页面结构
一期采用单页面多 Tab 方式，降低路由和菜单复杂度。

### Tab 1：实例管理
功能：

1. 实例列表。
2. 新增实例。
3. 编辑实例。
4. 删除实例。
5. 启用 / 禁用。
6. 连接测试。
7. 触发同步。
8. 按类型、状态、环境、关键字筛选。

列表字段：

1. 实例名称。
2. 类型。
3. 地址。
4. 默认库。
5. 环境。
6. 状态。
7. 版本。
8. 最近测试时间。
9. 最近同步时间。
10. 操作。

### Tab 2：结构浏览
功能：

1. 选择数据库实例。
2. 展示 Schema 列表。
3. 展示表列表。
4. 展示字段列表。
5. 展示索引列表。
6. 查看最近同步状态。

### Tab 3：SQL 控制台
功能：

1. 选择数据库实例和默认库。
2. 输入 SQL。
3. 执行只读查询。
4. 展示结果表格。
5. 展示耗时和返回行数。
6. 非只读 SQL 提示被拦截。

一期限制：

1. 不支持写 SQL。
2. 不支持多结果集。
3. 不支持长事务。
4. 不支持导出。

### Tab 4：查询审计
功能：

1. 查询审计列表。
2. 按实例、用户、状态、风险等级、时间筛选。
3. 展示 SQL 摘要、耗时、返回行数、错误信息。

## 表单字段
新增 / 编辑实例表单：

1. `name`：实例名称，必填。
2. `dbType`：数据库类型，必填。
3. `host`：主机地址，必填。
4. `port`：端口，必填。
5. `defaultDatabase`：默认库，可选。
6. `credentialId`：凭据，必填。
7. `environment`：环境，可选。
8. `businessSystem`：业务系统，可选。
9. `owner`：负责人，可选。
10. `tags`：标签，可选。
11. `remark`：备注，可选。

## 交互规则
1. 选择数据库类型时自动带出默认端口。
2. 创建或编辑后刷新实例列表。
3. 连接测试成功后更新版本和测试时间。
4. 同步成功后刷新结构浏览。
5. SQL 控制台默认展示安全提示。
6. 审计列表默认按时间倒序。

## 当前落地状态
1. Tab 1 已落地实例列表、新增、编辑、删除、启用、禁用、连接测试、同步结构和筛选。
2. Tab 2 已落地实例选择、元数据同步、Schema 列表、表列表、字段列表和索引列表。
3. 字段列表已展示敏感字段标记，敏感识别由后端按字段名关键字生成。
4. Tab 3 已落地只读 SQL 控制台，支持实例选择、Schema 选择、LIMIT、超时、执行结果动态表格、耗时、返回行数、审计 ID 和实际执行 SQL 展示。
5. Tab 4 已落地查询审计列表，支持关键字、实例、状态、风险、SQL 类型筛选，支持分页和 SQL 原文详情。
6. Tab 4 已落地查询审计 CSV 导出，导出时复用当前筛选条件。
7. 新增 / 编辑实例弹窗已调整端口布局，主机地址让出空间，端口输入框加宽。
8. PostgreSQL 查询控制台选择 Schema 时优先使用已同步 Schema，避免把默认库名误当成 Schema。

## 样式要求
1. 复用现有资产管理页面的卡片和表格风格。
2. 不引入新的 UI 框架。
3. 适配桌面和常见笔记本宽度。
4. 查询结果表格需要支持横向滚动。
